# 📋 Паспорт проекта: Studio Clicker

### 1. Общие сведения
* **Название проекта:** Studio Clicker
* **Тип проекта:** Игровое приложение (2D-кликер)
* **Учебная группа:** ГФ25-01Б
* **Срок реализации:** Апрель — Июнь 2026 года

### 2. Команда проекта (Подгруппа №2)
* **Ведущий разработчик (Unity/C#):** Студент 1 курса
* **Участники:** Елисей, Артемий,Санжирма.

### 3. Цели и задачи
* **Цель:** Создание прототипа игры с глубокой системой кастомизации персонажа
* **Ключевые задачи:**
    * Реализация механики клика и системы подсчета очков
    * Создание системы слоев одежды (шапка, кофта, штаны, обувь)
    * Разработка архитектуры на основе ScriptableObjects для хранения данных о предметах
    * Интеграция UI-магазина для смены скинов в реальном времени

### 4. Технические характеристики
* **Движок:** Unity 6
* **Язык программирования:** C# (с акцентом на ООП и работу с классами-наследниками)
* **Принципы разработки:** "Learning by doing" — самостоятельное написание кода и изучение архитектуры игровых систем

### 5. Особенности реализации
* Реализована динамическая смена спрайтов через скрипт `Skin.cs`
* Использование метафоры архитектурных путей для визуализации прогресса
* Поддержка расширения гардероба без изменения основного кода системы
